# Frontend Docs

`docs/frontend` 目前包含以下主要文件：

- [frontend-plan.md](./frontend-plan.md): 手機前端整體頁面規劃與主導航說明
- [live-alert-display.md](./live-alert-display.md): 即時預警頁的顯示規則與導向方式

## 文件分工

### 1. `frontend-plan.md`

說明：

- 前端主導航規劃
- 儀表板、趨勢報表、預警紀錄、設定頁的定位
- 各頁顯示重點與頁面邊界

### 2. `live-alert-display.md`

說明：

- 單筆即時預警頁
- 即時模式與歷史模式入口
- 上下區塊版面結構
- 異常摘要區、摘要說明卡與預警資訊區
