# Progress Plan

## 1. 這份文件在說什麼

這份文件用來整理目前專案的功能優先順序，以及各功能之間的前後依賴關係。

## 2. 功能優先順序

目前可先按照下面順序規劃：

1. 登入功能
2. 資料生成
3. 本地資料保存
4. 本地預警分析
5. 前端預警顯示
6. 本地後端同步
7. 伺服器資料保存
8. 伺服器後端健康分析
9. 各種報表設計
10. 伺服器部署與發佈手機App

## 3. 功能依賴關係

可先用下面表格理解各功能之間的關聯：

| 功能 | 依賴前置功能 |
| --- | --- |
| 登入功能 | 無 |
| 資料生成 | 無 |
| 本地資料保存 | 資料生成 |
| 本地預警分析 | 資料生成、本地資料保存 |
| 前端預警顯示 | 本地資料保存、本地預警分析 |
| 本地後端同步 | 本地資料保存 |
| 伺服器資料保存 | 登入功能、本地後端同步、本地預警分析 |
| 伺服器後端健康分析 | 伺服器資料保存 |
| 各種報表設計 | 登入功能、伺服器資料保存、伺服器後端健康分析 |
| 伺服器部署與發佈手機App | 各種報表設計 |

## 4. 使用方式

這份文件目前不估時間，只用來幫助團隊判斷先後順序。

如果之後功能拆得更細，可以再把每一項繼續往下拆成子任務。
