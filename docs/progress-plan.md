# Progress Plan

## 1. 這份文件在說什麼

這份文件用來整理目前專案的功能優先順序，以及各功能之間的前後依賴關係。

## 2. 功能優先順序

目前可先按照下面順序規劃：

1. 伺服器部署
2. 登入功能
3. 資料生成
4. 本地資料保存
5. 本地後端同步
6. 伺服器資料保存
7. 本地預警分析
8. 前端預警顯示
9. 伺服器後端健康分析
10. 各種報表設計

## 3. 功能依賴關係

可先用下面方式理解各功能之間的關聯：

```text
伺服器部署
  -> 登入功能
  -> 伺服器資料保存
  -> 伺服器後端健康分析
  -> 各種報表設計

資料生成
  -> 本地資料保存
  -> 本地後端同步
  -> 本地預警分析

登入功能
  -> 伺服器資料保存
  -> 各種報表設計

本地資料保存
  -> 本地後端同步
  -> 本地預警分析
  -> 前端預警顯示

本地後端同步
  -> 伺服器資料保存

本地預警分析
  -> 前端預警顯示
  -> 伺服器資料保存

伺服器資料保存
  -> 伺服器後端健康分析
  -> 各種報表設計

伺服器後端健康分析
  -> 各種報表設計
```

## 4. 使用方式

這份文件目前不估時間，只用來幫助團隊判斷先後順序。

如果之後功能拆得更細，可以再把每一項繼續往下拆成子任務。
