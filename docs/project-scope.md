# Project Scope

## 1. 這份文件在說什麼

這份文件用來整理專案目前要解決的問題、主要使用情境，以及之後實作時應優先對齊的方向。

## 2. 專案核心目標

HealthSync Alert 不只是記錄健康資料，而是希望同時做到兩件事：

- 即時異常偵測與預警
- 長期健康趨勢分析

## 3. 主要使用情境

目前可先用三個情境理解這個專案：

- 日常健康監測：使用者日常佩戴穿戴裝置，系統持續接收資料並在異常時提醒。
- 高風險族群監護：家屬或照護者可遠端監測受照護者狀態，出現危險訊號時立即預警。
- 離線環境操作：在沒有網路的環境下，手機端仍能先保存資料並做本地預警，待恢復連線後再同步回伺服器。

## 4. 目前最重要的系統方向

從報告內容來看，這個專案的核心不是單一畫面或單一 API，而是下面四件事：

- 建立本地短期資料層，支援離線操作
- 建立伺服器長期資料層，支援保存與分析
- 建立本地預警與同步流程
- 建立長期分析、圖表與歷史查詢能力

## 5. 後續待做重點

後續文件與功能可優先往下面幾個方向補：

- 使用者帳號與基本資料
- 即時健康資料與預警資料模型
- 本地資料同步到伺服器的流程
- 長期健康摘要、週期紀錄與歷史預警
- 預警規則與異常判斷條件
- API 介面與資料查詢方式
