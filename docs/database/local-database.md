# Local Database Spec

## 1. 這份文件在說什麼

這份文件用來定義手機端本地短期資料庫的責任與資料表方向。

## 2. 角色

本地短期資料庫負責：

- 接收高頻即時健康資料
- 支援離線暫存
- 支援本地即時預警
- 保存待同步資料

## 3. 資料表

目前本地端以四張表為主：

- 即時健康資料表
- 即時預警表
- 預警狀態表
- 同步紀錄表

## 4. 即時健康資料表

建議至少包含：

- 即時資料編號
- 心率
- 心率變異
- 血氧
- 活動狀態
- 紀錄時間
- 同步狀態

## 5. 即時預警表

建議至少包含：

- 即時預警編號
- 預警類型
- 初始嚴重程度
- 觸發原因
- 判斷開始時間
- 判斷結束時間
- 首次發生時間
- 同步狀態

## 6. 預警狀態表

建議至少包含：

- 預警狀態編號
- 即時預警編號
- 狀態
- 嚴重程度
- 狀態時間
- 狀態說明

## 7. 同步紀錄表

建議至少包含：

- 同步紀錄編號
- 同步開始時間
- 同步結束時間
- 同步狀態
- 同步資料範圍
- 同步資料筆數
- 失敗原因
- 重試次數
