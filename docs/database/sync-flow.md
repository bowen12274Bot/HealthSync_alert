# Sync Flow Spec

## 1. 這份文件在說什麼

這份文件用來整理本地短期資料庫與伺服器長期資料庫之間的同步方向。

## 2. 同步目標

同步流程的目的，是把本地端暫存與預警結果整理後送到伺服器端，作為長期保存與分析資料來源。

## 3. 基本流程

目前同步流程可先理解成：

1. 手機端持續接收即時健康資料
2. 本地端進行即時預警判斷
3. 本地端整理待同步資料
4. 恢復連線或到達同步時機後，上傳到伺服器
5. 伺服器寫入長期資料庫

## 4. 同步內容

同步內容目前至少包含：

- 即時健康資料整理後的週期紀錄
- 即時預警與預警狀態整理後的預警歷史
- 同步狀態本身的紀錄

## 5. 後續待補

- 同步批次格式
- 同步成功與失敗處理
- 重送與重試規則
- 本地資料何時可標記為已同步
