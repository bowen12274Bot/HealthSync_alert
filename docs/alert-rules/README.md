# Alert Rules Plan

## 1. 這份文件在說什麼

這份文件用來整理預警規則的方向，幫助後續開發區分哪些屬於即時預警，哪些屬於長期預警。

## 2. 預警規則的基本分工

目前可先分成兩類：

- 即時預警：針對短時間內的異常狀況快速提醒
- 長期預警：針對長時間趨勢變化提出風險提醒

## 3. 即時預警方向

即時預警目前可先聚焦在：

- 心率異常
- 血氧過低
- 多項數據交叉判斷後的危險狀態
- 無網路環境下仍能觸發的本地預警

## 4. 長期預警方向

長期預警目前可先聚焦在：

- 一段時間內的健康趨勢變化
- 每日摘要或週期統計中的異常模式
- 歷史預警累積後的風險判斷

## 5. 後續待做重點

- 定義每種預警的判斷條件
- 定義嚴重程度分級
- 定義預警狀態變化
- 釐清哪些規則在本地判斷，哪些交給伺服器判斷
