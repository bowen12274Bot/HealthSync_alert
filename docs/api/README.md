# API Plan

## 1. 這份文件在說什麼

這份文件用來整理目前預計的 API 方向，幫助後續開發知道 API 大致會分成哪些類型。

## 2. API 主要分工

目前可先分成三類：

- 即時異常檢測相關 API
- 長期分析與查詢相關 API
- 本地與伺服器同步相關 API

## 3. 即時異常檢測方向

這一類 API 主要處理本地或邊緣端的即時預警需求，例如：

- 即時狀況判定
- 未處理警報查詢

## 4. 長期分析與查詢方向

這一類 API 主要處理伺服器端的長期資料查詢，例如：

- 健康趨勢分析
- 歷史預警紀錄查詢
- 報表與圖表資料查詢

## 5. 同步相關方向

這一類 API 主要處理本地資料上傳到伺服器，例如：

- 批次同步上傳
- 同步成功或失敗狀態回報

## 6. 後續待做重點

- 把 API 分成 edge 與 cloud 兩層
- 補上 request / response 格式
- 定義同步資料的批次上傳格式
- 釐清哪些 API 先做驗證版，哪些留到正式版
